# ヒアリング依頼メールのひな形

依頼先は `interview-contacts.md`、当日の質問は `interview-questions.md`。
［ ］の部分を差し替えて使う。問い合わせフォームしかない業者には、本文をそのまま貼る。

**書き方の方針（2026-10-27 更新）**: 「シミュレーターの結果を見て直してほしい」ではなく、
**「現場でどう判断しているかを教えてほしい」**と頼む。相手は専門家として話す立場になり、
訪問・電話・Zoom・メールのどれでも受けてもらいやすい。
数値（傾き・長さ）や判定結果の図はメールに入れない。会えたときに見せる材料にする
（ピアノ運送株式会社に「一律の数値は答えられない」と辞退された経緯は `interview-contacts.md`）。

**2026-10-27 追記**: 相手はこちらのことを何も知らないので、冒頭で「スマートフォンのアプリを作っている」「何ができるか」「どう使うか」「何のためか」の順に説明する。
「このアプリは必要ですか」とは聞かない。初対面では気を遣って「あったら便利」と答えるだけで、需要の判断材料にならない。
代わりに「お客さんから事前に『入りますか』と聞かれるか、どう答えているか」という事実を聞く（質問4）。見積もりでの確かめ方（質問3）は、シナリオB（引っ越しで今ある家具を運ぶ）の需要を測るため（`decisions.md` 2026-10-27）。
業者はアプリの利用者ではなく、吊り上げ業者には仕事が減る話でもあるため。

送る前のチェック:
- ［ ］を全部埋めたか（名前・所属・連絡先・謝礼）
- 「この業者に聞きたい理由」の一文を、吊り上げ業者用／ピアノ運送用／家具店の配送用のどれかにしたか
- 「〇〇まで伺うこと」の地名を、その業者の所在地にしたか（`interview-contacts.md`）
- フォームに件名欄が無ければ、件名を本文の1行目に入れたか
- 本文に数値（「〇度」「〇cm」）と「合っていますか」が無いか
- 図は添付していないか（会えたときに持っていく）

突然のご連絡失礼いたします。神戸電子専門学校の学生で、［名前］と申します。
作業のご依頼ではなく、お話を伺いたくご連絡しました。

いま、スマートフォンのアプリを作っています。
家具を買う前に、「その家具が玄関から部屋まで運び込めるか」を調べられるアプリです。

使い方は、家の階段や廊下の幅・曲がり角の形などを入力し、買いたい家具の大きさを入れるだけです。
するとアプリが、「このソファは2階の踊り場で引っかかります」「この階段なら幅〇〇cmの家具まで入ります」と教えてくれます。
買ってから「部屋まで入らなかった」という失敗を、事前に防ぐのが目的です。
また、引っ越しのときに、今お使いの家具が新しい家に運び込めるかを、見積もりの段階で調べることにも使えるようにしたいと考えています。

ただ、アプリの計算でできるのは、家具と通路の寸法を比べることだけです。
実際には、同じ寸法でも運ぶ方の持ち方や、角での回し方によって、通る・通らないが変わると思っています。
その「現場の方が何を見て、どう判断されているか」を知らないまま作っても、現実と合わないアプリになってしまいます。

**［吊り上げ業者用］** 階段や廊下を通らなかった家具の吊り上げを専門にされている御社なら、「どこで、なぜ通らなかったのか」を一番たくさんご覧になっていると思い、ご連絡しました。
**［ピアノ運送用］** 重くて傾けにくいピアノを階段で運ばれている御社なら、階段での運び方の限界を一番よくご存じだと思い、ご連絡しました。
**［家具店の配送用］** 毎日のように家具を階段で運ばれている御社なら、下見や当日に何を見ているかを一番よくご存じだと思い、ご連絡しました。

伺いたいのは、次のようなことです。

1. 下見や当日に、階段や曲がり角のどこを見て「通る・通らない」を判断されていますか
2. 「通ると思ったのに通らなかった」という実際の例はありますか。どんな家具が、どんな階段のどこで止まったかを伺いたいです
3. 見積もりの段階で、家具が入るかどうかをどのように確かめていますか（下見に伺う、お客さんに写真や寸法を送ってもらう、など）
4. お客さんから事前に「この家具は入りますか」と聞かれることはありますか。そのとき、どのようにお答えになっていますか
5. 「お客さんがこれを事前に分かっていてくれれば助かる」ということがあれば、ぜひ教えてください

お時間は30分ほどで十分です。［所在地］まで伺うことも、お電話や Zoom、メールでのご回答でも、ご都合のよい方法で構いません。
日時もご指定ください。
