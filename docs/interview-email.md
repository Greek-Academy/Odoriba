# ヒアリング依頼メールのひな形

依頼先は `interview-contacts.md`、当日の質問は `interview-questions.md`。
［ ］の部分を差し替えて使う。問い合わせフォームしかない業者には、本文をそのまま貼る。

**書き方の方針（2026-10-27 更新）**: 「シミュレーターの結果を見て直してほしい」ではなく、
**「現場でどう判断しているかを教えてほしい」**と頼む。相手は専門家として話す立場になり、
訪問・電話・Zoom・メールのどれでも受けてもらいやすい。
数値（傾き・長さ）や判定結果の図はメールに入れない。会えたときに見せる材料にする
（ピアノ運送株式会社に「一律の数値は答えられない」と辞退された経緯は `interview-contacts.md`）。

送る前のチェック:
- ［ ］を全部埋めたか（名前・所属・連絡先・謝礼）
- 「この業者に聞きたい理由」の一文を、吊り上げ業者用／ピアノ運送用／家具店の配送用のどれかにしたか
- 本文に数値（「〇度」「〇cm」）と「合っていますか」が無いか
- 図は添付していないか（会えたときに持っていく）

［所属（例: 神戸電子専門学校ITエキスパート学科の3年生）］で、家具が玄関から部屋まで**運び込めるか**を、買う前に判定するアプリを作っています。
階段や廊下の形を入力すると、「この階段ならどのくらいの家具まで入るか」「どこで引っかかるか」が分かるようにするものです。

ただ、机の上で計算できるのは家具と通路の寸法だけで、**実際に運ぶ方が現場で何を見て「通る・通らない」を判断しているか**が分かりません。
そこを教えていただかないと、現場で役に立つものになりません。

**［吊り上げ業者用］** 階段や廊下を通らなかった家具の搬入を専門にされている御社なら、どこで、なぜ通らなかったのかを一番よくご存じだと思い、ご連絡しました。
**［ピアノ運送用］** 重くて傾けにくいピアノを階段で運ばれている御社なら、階段での運び方の限界を一番よくご存じだと思い、ご連絡しました。
**［家具店の配送用］** 毎日のように家具を階段で運ばれている御社なら、下見や当日に何を見ているかを一番よくご存じだと思い、ご連絡しました。

伺いたいのは、主に次の2点です。

1. 下見や搬入の当日、階段や曲がり角のまわりで**何を見て、どう判断されているか**（測るところ、見て決めるところ、人数や運び方の決め方など）
2. 「通ると思ったのに通らなかった」**実際の例**。どんな家具を、どんな階段や廊下で運ぼうとして、どこで止まったか

このほか、「こういうことが事前に分かっていれば助かる」というご意見があれば、ぜひ伺いたいです。

お時間は30分ほどで、お伺い（神戸・大阪近辺でしたら伺えます）、お電話、Zoom、メールでのご回答など、ご都合のよい方法で構いません。
日時もご指定ください。
［謝礼: 例「心ばかりですが謝礼として〇〇円をお渡しします」／不要なら削る］
伺った内容はアプリの設計に反映するためにだけ使い、御社名を外に出す場合は事前にご確認いただきます。
